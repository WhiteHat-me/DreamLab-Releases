🌌 DreamLab

«A coding laboratory built for dreamers who code anywhere.»

DreamLab is a mobile-first development environment designed to turn an Android device into a practical coding laboratory.

It brings together code editing, project execution, a native terminal, Git/GitHub workflows, and developer utilities into one place — built with the goal of making serious development possible even when you don't have access to a traditional PC.

---

✨ Why DreamLab?

Most mobile code editors focus on editing files.

DreamLab aims to go further.

It is designed around the idea that a phone should be capable of being more than a text editor — it should be a real development environment.

Whether you're experimenting with C++, running Python, working with web technologies, managing Git repositories, or simply exploring the command line, DreamLab provides a unified workspace for it.

«Your device is small. Your projects don't have to be.»

---

🚀 Features

💻 Code Editor

Write and manage source code directly from your Android device.

- Multi-file projects
- Multiple tabs
- Syntax-aware editing
- Project file management
- Run individual files
- Run projects
- Support for multiple programming languages

---

🖥️ Native Terminal

DreamLab includes a terminal designed to feel like a real development environment rather than a simulated command prompt.

Use it to:

- Execute shell commands
- Compile programs
- Run scripts
- Navigate project directories
- Inspect files
- Work with Git
- Use DreamLab's custom developer commands

Example:

dream git-help

The terminal is intended to become one of the central parts of the DreamLab experience.

---

⚡ Code Execution

DreamLab can execute programs directly from the development environment.

For example, C++ projects can be compiled using:

g++ main.cpp

The goal is to make experimenting with compiled and interpreted languages accessible directly from Android.

---

🧩 Project Execution

DreamLab supports running projects rather than treating every source file as an isolated document.

This allows developers to work with:

Project/
├── main.cpp
├── utils.cpp
├── utils.h
└── README.md

instead of being limited to one-file experiments.

---

🌐 Web Development

DreamLab is designed to support experimentation with web technologies directly from mobile.

Potential workflows include:

- HTML
- CSS
- JavaScript
- Local development servers
- Project-based web applications

---

🐙 Git & GitHub

Git is a first-class part of the DreamLab workflow.

DreamLab aims to make common Git operations accessible without leaving the development environment.

Examples include:

git status
git add .
git commit
git push

GitHub integration is intended to make it possible to move naturally between:

Code → Commit → Repository → Build → Release

---

🛠️ Dream Commands

DreamLab includes its own custom command family:

dream

These commands are intended to provide DreamLab-specific utilities and developer guidance.

For example:

dream git-help

The command system is designed to grow alongside DreamLab.

---

🏗️ Development Philosophy

DreamLab follows a few core principles.

1. Everything in One Place

Editing, terminal usage, execution and Git workflows should feel like parts of the same environment.

2. Don't Hide the Developer

Abstractions are useful, but developers should still be able to understand what's happening underneath.

3. Mobile Doesn't Mean Toy

A mobile IDE doesn't have to behave like a simplified text editor.

DreamLab aims to provide genuinely useful development capabilities while respecting the limitations of Android.

4. Experimentation First

DreamLab should make experimentation cheap.

Try an idea → run it → observe → modify → repeat.

When reporting an issue, try to include:

1. What you were trying to do
2. What you expected
3. What actually happened
4. Relevant terminal output
